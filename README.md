# OnlineNetSoft WhatsApp Automation SaaS

Professional WhatsApp Automation & CRM Platform built with:

- React + Vite
- Node.js + Express
- PostgreSQL + Prisma
- Redis + BullMQ
- Socket.IO
- Docker + Nginx
- AI Chatbot Support

---

# Features

- Multi-user SaaS
- WhatsApp Automation
- Shared Inbox
- Broadcast Campaigns
- AI Chatbot
- CRM System
- Team Workspaces
- Analytics Dashboard
- Affiliate System
- Billing & Subscription
- Queue Processing
- Real-time Messaging
